# 프로젝트 이력 (History)

> 이 파일은 모든 프로젝트의 진행 이력을 시간순으로 기록한다.
> 세션이 중단됐다가 재개될 때 이 파일을 먼저 참고하여 컨텍스트를 복원한다.

## 기록 형식

```markdown
### [날짜] [페르소나] [단계] — [작업 제목]
- **진행 사항**: 
- **이슈**: 
- **조치**: 
- **미결 사항 / 개선 포인트**: 
```
