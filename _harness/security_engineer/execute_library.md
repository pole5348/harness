# 실행 단계 라이브러리 (Execute Library)

> 실행(Execute) 에이전트가 사용하는 MCP 서버, Skills, 도구를 프로젝트별로 기록한다.
> 새 프로젝트 시작 시 해당 프로젝트 섹션을 추가한다.

---

## 기본 허용 도구 (모든 프로젝트 공통)

| 도구 | 용도 |
|---|---|
| Read | 파일 읽기 |
| Write | 파일 생성 |
| Edit | 파일 수정 |
| Bash | 쉘 명령 실행 |
| TodoWrite | 태스크 추적 |

---

## 프로젝트별 추가 라이브러리

### [템플릿 — 새 프로젝트 시 복사하여 사용]

```markdown
### [프로젝트명] — [날짜]

#### MCP 서버
| MCP 서버 | 용도 | 연결 상태 |
|---|---|---|
| 예: GitHub MCP | 레포 관리 | 미연결 |

#### Skills
| Skill | 용도 |
|---|---|
| 예: security-review | 보안 검토 자동화 |

#### 추가 Bash 도구
| 도구/명령 | 용도 |
|---|---|
| 예: npm audit | 의존성 취약점 스캔 |

#### 외부 의존성 (SBOM 예비 목록)
| 패키지 | 예상 버전 | 라이선스 |
|---|---|---|
```
