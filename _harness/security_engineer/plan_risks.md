## 감수해야 할 리스크 (사용자 명시 수용)

> 사용자가 의식적으로 도입 보류·수용을 선택한 항목들. 향후 운영 중 발견되면 재계획 대상.

1. **자연어 프롬프트 인젝션 검사 미도입** (PM-1 결정) — 향후 검토.
2. **위협 모델 정식 작성 미수행** (보안-9 보류).
3. **`rules/` 변조 감지 미도입** (보안-6 보류) — pre-commit + git diff 알림으로 부분 완화.
4. **토큰 베이스라인 측정 / ROI 정량 평가 미수행** (재무-5,6 보류) — 9단계 4주 후 자가 점검 1회로 부분 완화.
5. **위험 Bash 차단 카테고리 부재** — L4도 사용자 토큰 입력 시 진행. 의미 토큰 + 5초 카운트다운으로만 인지 비용 강제.
6. **GPG signed commit 미도입 (시작 시점)** — chmod 600 단독 의존. 운영 안정화 후 재검토.
7. **위험 Bash L1~L3 매번 다른 표현 출력 미구현** — L4만 차별화.
8. **Continuous Learning ROI 정량 평가 무시** — 4주 후 정성 평가.
9. **단위 테스트 작성 주체 미결정** — 9단계 종료 시 사용자와 재논의.
10. **status.md `git push` 시 git history 노이즈** (FIN-5 사용자 수용).
11. **`user_decisions` 카테고리 자동 반영 위험** — 직전 10분 외부 입력 자동 첨부, 그 이전 영향은 추적 불가.
