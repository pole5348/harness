# 4단계: `/se:backup` + status.md (메타데이터만, 이슈 제목 마스킹) + 변경 없으면 skip

**상태**: [ ] 미실행
**선행 의존**: 3단계 (safe_write.py, merge_history.py)
**모델**: Sonnet (실행)

## 태스크
- **이번 v5 plan에 표준 로드맵 헤더가 이미 포함되어 있음** — 별도 변환 불필요
- 향후 plan.md는 `/se:confirm` 시 표준 헤더 자동 생성 (`commands/se/confirm.md` 갱신)
- `_harness/status.md` 스키마 정의:
  ```markdown
  # Project Status
  - 마지막 갱신: <timestamp>
  - 현재 페르소나: 보안 엔지니어
  - 현재 단계: 실행 (3/10)
  - 로드맵 위치: 3단계 시크릿 마스킹 (in progress)
  - 진행 중 이슈: 2건 (ID: ISSUE-001, ISSUE-003)
  - 해결 이슈 (이번 주): 1건 (ID: ISSUE-002, 해결일 YYYY-MM-DD)
  - 다음 예정 단계: 4단계 /se:backup 커맨드
  ```
- `commands/se/backup.md` 작성 (PM-4 수용 — 수동 운영 + skip 로직):
  - **수동 트리거 전용** (자동/Stop 훅 호출 금지). 첫 줄에 명시.
  - **변경 없으면 skip**: 마지막 status.md mtime + plan.md mtime + history*.md mtime 비교, 모든 파일이 마지막 backup 이후 변경 없으면 "변경 없음 — skip" 메시지만 출력하고 종료. (결정론 비교, LLM 호출 없음)
  - 변경이 있을 때만:
    - `scripts/merge_history.py` 호출 (결정론) — 분기 history 통합
    - plan.md `## 로드맵 진행률` 표 정규 파싱
    - 이슈 추출: ID/제목만 (제목은 `safe_write.py`로 마스킹)
    - status.md를 `safe_write.py`로 작성
